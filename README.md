# 🏥 Hospital Care+ - Sistema de Triagem

Projeto desenvolvido utilizando HTML, CSS e Bootstrap com o objetivo de simular um sistema simples de triagem hospitalar.

## 📋 Funcionalidades

- Página inicial simples
- Formulário de triagem
- Cadastro de dados pessoais
- Informações de saúde
- Classificação de risco
- Layout responsivo com Bootstrap

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- Bootstrap 5

## 📁 Estrutura do Projeto

```bash
📦 hospital-care
 ┣ 📄 index.html
 ┣ 📄 style.css
 ┗ 📄 README.md
```

## 🚦 Classificação de Risco

- 🔵 Azul — Não urgente
- 🟢 Verde — Pouco urgente
- 🟡 Amarelo — Urgente
- 🔴 Vermelho — Emergência

## ▶️ Como Executar

1. Baixe os arquivos do projeto
2. Abra o arquivo `index.html` no navegador

Projeto criado para prática de:
